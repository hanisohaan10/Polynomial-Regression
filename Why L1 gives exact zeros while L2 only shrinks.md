## Discussion (Deliverable 7)

**Why L1 gives exact zeros while L2 only shrinks.** The two penalties shrink coefficients for fundamentally different geometric reasons. The L2 term `½λ‖w‖²` is differentiable everywhere and adds curvature around the origin: the subgradient always points toward zero but never forces a coordinate to land exactly on it, so the ridge optimum `w = (ΦᵀΦ + λI)⁻¹Φᵀt` is reached strictly *inside* the ball with all coefficients non-zero (just smaller). In contrast, the L1 term `λ‖w‖₁` has a *non-differentiable corner at every axis*: at `wⱼ = 0` the subdifferential is the interval `[−λ, +λ]`, so the optimality condition `−Φⱼᵀr + λ ∂|wⱼ| ∋ 0` is satisfiable *at* `wⱼ = 0` for any residual correlation with `|Φⱼᵀr| ≤ λ`. Coefficients whose feature–residual correlation is small enough therefore get pinned to exactly zero, while the rest stay non-zero. The coefficient-path plot shows this clearly: each `wⱼ` shrinks roughly linearly as λ grows until it hits the "chatter zone" `|wⱼ| < 2ηλ`, then stays there forever. Ridge, in contrast, has a smooth path that decays toward — but never reaches — zero. The table from Deliverable 5 confirms this at the best λ for each method: **[Ridge: test RMSE = ___, ‖w‖₂ = ___, #(|wⱼ| < 0.01) = ___]** versus **[Lasso: test RMSE = ___, ‖w‖₂ = ___, #(|wⱼ| < 0.01) = ___]** — same test accuracy, but the L1 fit achieves it with far fewer effective parameters.

**What happens past λ\*.** As λ increases beyond λ\*, the training RMSE rises monotonically because the penalty term starts dominating the objective, forcing the fit further from the training targets. The test RMSE first stays flat (λ near λ\* — the model is still well-matched to the data), then also rises as over-shrinkage kicks in: bias grows faster than any remaining variance reduction, so total error increases. At very large λ, essentially every coefficient is driven to zero and the model collapses to the null predictor ŷ = 0, at which point both train and test RMSE converge to `√mean(t²)` on their respective sets.
